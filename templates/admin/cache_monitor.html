How caching works here
  • Public pages (home, pricing, about, FAQ, privacy, terms, tournament list, organization directory/detail) are full-page cached for anonymous visitors. Logged-in users always get a fresh render.
  • Dynamic data (court availability, reservations, payments, dashboards, live scoring, notifications) is never cached.
  • Query-level caches hold featured lists, CMS settings and page content; they are invalidated automatically when the underlying records change.
  • Template fragments (footer, homepage hero/stats/gallery) are cached with the same invalidation.
  • Session data lives in {% if cache_backend == 'redis' %}Redis (cached_db engine){% else %}the database (db engine){% endif %} and is never cleared by cache invalidation.
